# Vitamin C Knowledge Website
A static educational website about Vitamin C, created as a capstone project for the course **Chemical Multimedia Software Design** at Sun Yat-sen University.

### Overview

This project presents chemistry knowledge about Vitamin C through a user-friendly multi-page website. The site includes pages for biological functions, physicochemical properties, experimental detection, Vitamin C in fruits and vegetables, and related standards.

### Project Highlights

- Designed website UI/UX blueprint using Photoshop, including homepage, category pages, and content pages
- Built a 14-page static website with HTML and CSS
- Applied CSS cascade, selector specificity, and inheritance to maintain consistent styling across pages
- Used slicing tools to extract visual assets and support consistent web layout
- Designed for cross-browser compatibility and a consistent user experience

### How to View Locally

Open `docs/index.html` in a browser.
